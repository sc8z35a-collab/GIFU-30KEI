# GIFU 30KEI

岐阜県の40候補を一次資料で調べ、森・渓谷・田園・湖の30地点を選んだスマートフォン専用ガイド。

縦画面は写真を大きく表示し、横画面は写真と案内を並べます。開くと風景から始まり、スワイプ、写真の拡大、下の目盛りをなぞる操作、ランダム選択で移動できます。11地点には別の実景写真があり、選んだ写真は保存されます。

出発地は愛知県名古屋市天白区の原駅。各地点に住所、Google Maps、移動方法のタグ、原駅からの往復燃料費を掲載しています。燃料費は一般道を優先した道路経路を使い、燃費12～18km/L、ガソリン160～190円/L、上限側の距離補正10％で算出。確認した現地料金は別に表示します。

実景写真41枚と日本語フォントを同梱。設定の「写真と案内を保存」で、PWAの風景と案内をオフライン保存できます。Android APKへの移植に向け、サーバーを必要としないHTML/CSS/ES Modulesで構成しています。

製作者：TAKU / 制作AI：GPT 6 ASTRA MAX ONLY

## ファイル

- `dist/`：配信するサイト
- `research/selection.json`：40候補の出典と選定記録
- `research/photo-records.json`：写真の作者・ライセンス・加工記録
- `research/route-budgets.json`：道路側の到着地点と予算算定
- `research/build-data.py`、`research/calculate-budgets.py`：掲載データの生成
